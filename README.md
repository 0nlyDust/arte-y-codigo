# Arte y Código — Portfolio Windows 98

Portfolio web responsive creado con **React + Vite**, inspirado en la estética de un escritorio retro tipo **Windows 98** en tonos azul claro y rosa pastel.

## Concepto

Este proyecto transforma un portfolio personal en un escritorio interactivo con estética noventera. La interfaz simula un sistema operativo clásico con iconos, ventanas, barra de tareas y una composición visual inspirada en Windows 98.

La idea principal es presentar proyectos de informática, arte digital y diseño web de una forma más creativa, visual y personal.

## Características

* Escritorio retro con fondo azul estilo Windows 98.
* Barra de tareas rosa pastel con botón de inicio.
* Iconos personalizados en formato SVG.
* Ventanas interactivas que se pueden abrir, cerrar, minimizar, maximizar y mover.
* Ventana principal tipo aplicación de escritorio.
* Sección de proyectos tipo explorador de archivos.
* Imagen de nubes pastel para el proyecto de dashboard.
* Diseño adaptado a ordenador y móvil.
* Estética visual en tonos azul claro, rosa y lavanda.

## Ejecutar en local

Instala las dependencias:

```bash
npm install
```

Ejecuta el proyecto en modo desarrollo:

```bash
npm run dev
```

## Crear versión final

Genera la build de producción:

```bash
npm run build
```

La carpeta `dist/` contiene la web lista para publicar.

## Publicación

Este proyecto puede publicarse fácilmente en GitHub Pages u otro servicio de hosting estático.
