# Portfolio Windows 95 — Arte y Código

Página web responsive creada con React + Vite a partir del portfolio original.

## Concepto

Portfolio con estética de escritorio Windows 95 en tonos azul claro y rosa. Incluye:

- Escritorio con iconos interactivos.
- Ventanas estilo retro para información personal, habilidades y contacto.
- Barra de tareas con botón de inicio.
- Sección de proyectos tipo explorador de archivos.
- Diseño adaptado a móvil y ordenador.

## Contenido usado

Se mantiene la información del ZIP original:

- María, estudiante de Ingeniería Informática.
- Proyectos: Hunt the Wumpus, Duck Pond, Covid-19 Dashboard y 3D Room.
- Stack: React, Vite, JavaScript, CSS, Canvas API y GitHub Pages.
- Contacto, GitHub y LinkedIn.
- Imágenes del proyecto original.

## Ejecutar en local

```bash
npm install
npm run dev
```

## Crear versión final

```bash
npm run build
```

La carpeta `dist/` contiene la web lista para publicar.
